# Runyth Pet Command v1.3.0 Quick Start

## GM

1. Open **Runyth Pet Command Manager** and register a pet plus its owner Actor(s).
2. Configure the pet's attitude, movement, random-behaviour weights, and target-pool defaults.
3. In **Relationships**, enable **Player behaviour targets** only for owner relationships whose players should be able to choose random target pools.
4. Issue commands from the Manager, or select an owner token and open **Owner Perspective** to use the player-style workflow yourself.

## Player

1. Open the Runyth Pet Command player panel.
2. Select one of your active pet relationships.
3. Select a command and a command target when required.
4. If the GM enabled behaviour-target choices for that relationship, choose which target pools may be used if the command fails.
5. Roll the command. The active GM validates and resolves the request.

## Movement

Successful movement-capable commands and moving random reactions move the pet token automatically when global and pet movement are enabled. A successful explicit **Attack** moves toward the selected target before the normal D&D 5e attack roll.
